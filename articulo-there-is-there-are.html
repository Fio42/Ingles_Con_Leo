There is y there are en inglés: reglas, ejemplos y ejercicios

Inglés con Leo · 6 min de lectura

There is significa “hay” cuando hablas de una cosa o algo incontable; there are significa “hay” cuando hablas de varias cosas. Úsalos para describir una habitación, una ciudad, un hotel o lo que encuentras en el supermercado.

Respuesta rápida
  • There is a bed in the room. → Hay una cama.
  • There are two windows. → Hay dos ventanas.
  • There isn't any milk. → No hay leche.
  • Are there any shops nearby? → ¿Hay tiendas cerca?

There is: una cosa o algo incontable

Usa there is con un sustantivo singular o una cosa que no cuentas por unidades, como agua, leche o dinero.

There is a supermarket near my house.
Hay un supermercado cerca de mi casa.
There is milk in the fridge.
Hay leche en la nevera.

There are: varias cosas

Usa there are con un sustantivo plural.

There are three chairs in the kitchen.
Hay tres sillas en la cocina.
There are many parks in this city.
Hay muchos parques en esta ciudad.

La estructura en afirmativo

SituaciónEstructuraEjemplo
SingularThere is + singularThere is a hotel.
IncontableThere is + incontableThere is coffee.
PluralThere are + pluralThere are four rooms.

En conversación, there is suele contraerse a there's: There's a problem. Evita usar there's antes de un plural en escritura cuidada: mejor There are two problems.

Forma negativa: there isn't y there aren't

Para decir que algo no existe, añade not. La forma corta es la que más escucharás.

Singular / incontablePlural
There isn't a bathroom here.There aren't any buses now.
There is not any sugar.There are not any tickets.

En negativas usamos mucho any: There isn't any water, There aren't any tables. Para entender mejor esa palabra sin convertir esta guía en otra lección, visita some y any.

Preguntas y respuestas cortas

Para preguntar, mueve is o are al inicio.

PreguntaRespuesta corta
Is there a pharmacy nearby?Yes, there is. / No, there isn't.
Are there any rooms available?Yes, there are. / No, there aren't.

Ejemplos que puedes usar

En una habitación

There is a lamp next to the bed. There are two towels in the bathroom.

En la ciudad

There is a bus stop on this street. There are several restaurants near the station.

En un hotel o supermercado

Is there a lift in the hotel? Are there any fresh vegetables?

Las palabras de lugar te ayudarán a dar más detalles: repasa in, on y at en inglés y usa el vocabulario básico para crear tus propias frases.

Errores comunes

❌ There are a restaurant near here.
✅ There is a restaurant near here.

A restaurant es singular, por eso usamos there is.

❌ Is there any hotels?
✅ Are there any hotels?

Hotels es plural, así que la pregunta necesita are.

Ejercicio: elige la opción correcta

Práctica0 de 4 respondidas

1. ___ a bank near the hotel.

2. ___ any eggs in the fridge?

3. There ___ any chairs in this room.

4. ___ milk for breakfast?

Resumen fácil

Piensa primero en la cosa que viene después: una o incontable = there is; varias = there are. Luego cambia el orden si haces pregunta y añade not si niegas. Si quieres repasar is y are, consulta el verbo to be.

Preguntas frecuentes

¿There is también sirve para agua o comida?

Sí. Agua, leche y comida son normalmente incontables: There is water on the table.

¿Puedo usar some con there are?

Sí, en afirmativo: There are some apples. En preguntas y negativas es frecuente usar any.
