Condicionales 1 y 2 en inglés: cuándo usar will y cuándo would

Inglés con Leo · 6 min de lectura

Las oraciones con if (si) se dividen en dos casos que se confunden mucho. El primer condicional habla de algo que puede pasar de verdad y lleva will. El segundo condicional habla de algo imaginario o poco probable y lleva would. En estos dos condicionales, lo que va justo después de if no lleva will ni would. Con esa idea evitas los errores más comunes entre hispanohablantes.

Respuesta rápida
  • Condicional 1: if + presente, will + verbo. If you practice, you will improve.
  • Condicional 2: if + pasado, would + verbo. If I had wings, I would fly.
  • Después de if no va will ni would: if you practice, no if you will practice.

Condicional 1: algo que puede pasar de verdad

Usa el primer condicional cuando la situación es real y posible: puede ocurrir mañana, esta semana o cuando llegues. La estructura es if + presente simple, will + verbo base.

If you practice every day, you will improve quickly.
Si practicas todos los días, mejorarás rápido.
If the train is late, I will call you.
Si el tren llega tarde, te llamaré.
If it snows, they won't travel.
Si nieva, no viajarán.

Aunque hablas del futuro, la parte del if va en presente. En español también decimos si llueve (presente), no si lloverá. El error aparece cuando traducimos pensando en el futuro y ponemos will después de if.

❌ If you will practice, you will improve.
✅ If you practice, you will improve.
❌ If he studies, he would pass.
✅ If he studies, he will pass.

El resultado también puede ir con won't, con una orden o con can: If you finish early, you can leave.

Condicional 2: algo imaginario o poco probable

Usa el segundo condicional para situaciones imaginarias, que no son ciertas ahora o que casi no van a pasar: si tuviera alas, si fuera millonario. La estructura es if + pasado simple, would + verbo base. El pasado aquí no habla del pasado: es la señal de que la situación es imaginaria.

If I had wings, I would fly to work.
Si tuviera alas, volaría al trabajo.
If she lived near the sea, she would swim every morning.
Si viviera cerca del mar, nadaría cada mañana.
If I were you, I would talk to him.
Si yo fuera tú, hablaría con él.

Con el verbo to be se usa were con todas las personas: If I were, if he were, if she were. En conversación informal se oye if I was, pero were es la forma recomendada, sobre todo al dar consejos con If I were you.

❌ If I would have more time, I would travel.
✅ If I had more time, I would travel.
❌ If I have wings, I would fly.
✅ If I had wings, I would fly.
❌ If they were richer, they will move.
✅ If they were richer, they would move.

Condicional 1 y 2 en una tabla

SituaciónIf + ...ResultadoEjemplo
Posible, realpresente simplewill + verboIf it is cold, I will wear a coat.
Imaginario, poco probablepasado simple (were)would + verboIf I were taller, I would play volleyball.

La coma separa las dos partes cuando el if va primero: If it rains, we will stay home. Si lo pones al final, no lleva coma: We will stay home if it rains. Si quieres repasar el futuro con will, mira nuestra guía de will vs going to.

Ejercicios: condicional 1 o 2

Completa o corrige cada oración. Toca cada una para ver la respuesta.

1. Posible: If it ___ (be) cold tonight, I ___ (wear) a jacket.

If it is cold tonight, I will wear a jacket. (algo posible: presente + will)

2. Imaginario: If I ___ (have) a bigger kitchen, I ___ (cook) for everyone.

If I had a bigger kitchen, I would cook for everyone. (algo imaginario: pasado + would)

3. Corrige: "If you will arrive early, we will start sooner."

If you arrive early, we will start sooner. (después de if no va will)

4. Corrige: "If I would be a teacher, I would give less homework."

If I were a teacher, I would give less homework. (después de if no va would: se usa were)

5. Posible: If he ___ (not / hurry), he ___ (miss) the flight.

If he doesn't hurry, he will miss the flight. (es algo que puede pasar: presente + will)

6. Imaginario: If I ___ (be) you, I ___ (take) the job.

If I were you, I would take the job. (consejo imaginario: were + would)

Preguntas frecuentes sobre los condicionales 1 y 2

¿Cuál es la diferencia entre el primer y el segundo condicional?

El primero habla de algo que puede pasar de verdad y usa if + presente simple con will en el resultado. El segundo habla de algo imaginario o poco probable y usa if + pasado simple con would en el resultado.

¿Se puede usar will después de if?

No en estos condicionales. Después de if va el presente simple (If you study, you will pass) o el pasado simple (If you studied, you would pass), nunca will ni would.

¿Por qué se dice if I were y no if I was?

En el segundo condicional se usa were con todas las personas, incluso con I, he y she: If I were you, I would call him. If I was se oye en conversación informal, pero were es la forma recomendada.

¿Dónde va la coma en una oración con if?

Si la parte del if va primero, se separa con coma: If it rains, we will stay home. Si va al final no lleva coma: We will stay home if it rains.
